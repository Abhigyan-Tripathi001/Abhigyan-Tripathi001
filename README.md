## 🏥 DR-APP — Full-Stack Healthcare Platform

**DR-APP** is a full-stack healthcare web application for online doctor appointment booking between patients, doctors and administrators.

Built using the **MERN stack**, with integrated payments and AI/ML-powered healthcare tools.

### 🔧 Tech Stack

`React.js` `Tailwind CSS` `Node.js` `Express.js` `MongoDB`  
`Razorpay` `Cloudinary` `JWT` `AI` `Machine Learning`

### ✨ Features

- 👨‍⚕️ Doctor appointment booking
- 👤 Patient dashboard
- 🩺 Doctor dashboard
- 👨‍💼 Admin dashboard
- 📅 Appointment management
- 💳 Razorpay payment integration
- ⭐ Doctor reviews & ratings
- 🔐 Authentication & authorization
- 🤖 AI Symptom Checker
- 🧠 AI Health Assistant
- ❤️ ML-based Heart Disease Prediction
- 🩸 ML-based Diabetes Prediction

🔗 **Live Project:**  
https://dr-app-ai-integration-frontend.vercel.app/
